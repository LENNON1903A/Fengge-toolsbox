# 🔧 风哥万能工具箱

一个开箱即用的 PDF 在线工具箱，浏览器打开就能用。

## 访问地址

👉 **https://fengge-toolbox.netlify.app**（推荐，始终最新版）

## 功能

- 🖼️ **图片转PDF** — 把多张图片合并成一个 PDF
- 📄 **PDF转图片** — 把 PDF 每页导出为 PNG 图片
- 📑 **提取页码** — 提取 PDF 指定页面
- 📋 **插入页面** — 向 PDF 指定位置插入内容
- 🔄 **替换页面** — 替换 PDF 的某一页
- 📎 **合并PDF** — 多个 PDF 合并成一个

## 特点

- 纯浏览器处理，不上传文件到服务器
- 双击 HTML 即可离线使用
- 在线版自动检查更新

## 技术栈

- pdf-lib / pdf.js / JSZip
