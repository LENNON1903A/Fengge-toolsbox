# 风哥万能工具箱

一个可在浏览器中使用的 PDF 工具箱。在线版：[fengge-toolbox.netlify.app](https://fengge-toolbox.netlify.app)。

## 功能

- 图片转 PDF
- PDF 转图片
- 提取指定页面
- 插入页面
- 替换页面
- 合并多个 PDF

## 使用方式

可访问上方在线版，也可下载仓库中的 `index.html` 后在浏览器中打开。README 当前说明该页面可离线使用；具体浏览器兼容性和离线依赖应在目标设备上确认。

工具说明为纯浏览器本地处理，文件不上传服务器。处理敏感文件前，建议断网试用并确认浏览器网络面板没有文件上传请求。

## 技术信息

页面使用 pdf-lib、pdf.js 和 JSZip。完整页面目前集中在单个较大的 `index.html` 文件中，更新在线版时以仓库代码为准。仓库根目录的 `version.txt` 用于记录版本。

## 维护建议

- 每次发布同步更新 `version.txt` 和此处的变更说明。
- 修改或升级第三方库时记录版本和来源。
- 在常见浏览器中检查文件导入、页面选择、导出和大文件处理。
- 公开发布前补充许可证，以及第三方依赖的许可证信息。
